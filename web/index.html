What this does not do

  • Nothing is ever burned on a sale. The token can cut sales above a 24-hour average, but that needs an oracle and this one answers "not ready" forever. Immutable. That rule never fires. the detail
  • Virtual liquidity is not liquidity. Before bonding the only ETH behind the price is what buyers put in.
  • One wallet skips the daily cap — the dev's. One address, public, capExempt reads true for it on chain.
  • 1% of every buy and every sell goes to the dev, in ETH.
  • Slippage gets 46% worse at bonding, not better. Only the real ETH goes into the pool, and more virtual ETH does not buy depth — what a size gets.
  • It is not permissionless yet. One wallet can deploy and nobody else can launch. Anyone can BUY.
  • Most tokens never bond. Normal outcome, not the failure case.
  • No audit, no testnet run.
