Check it yourself, in three hops

Nobody should take an address on trust because a website is confident. The point of the loop below is that every hop is checkable independently, and it closes: the chain points at this site and this site points at the chain. A copy of this page can reproduce the words. It cannot reproduce the loop.

HOP 1 · CHAIN → SITE

The token names this site, permanently.

The mint's metadata was pinned before the token existed and the launcher cannot edit it afterwards. Open the token on pump.fun and read the website field: it is snoozebear.xyz. A copycat can put our name and our picture on their token. They cannot put their address on our site.

HOP 2 · SITE → CHAIN

This page names the token, and only after reading it back.

The address above was not typed. It was written by pumpfun.py publish, which takes it from the launch record, reads the account off the chain first, refuses it if it is not a token mint, and refuses to overwrite a different address that is already here. Filling a blank and replacing a live address are different events and only the first one happens automatically.

HOP 3 · SITE → ITSELF

The page you are reading is hashed in public.

The repository's README publishes a sha256 for every page under a build tag. Hash this file and compare. That is what makes hop 2 worth anything: without it, "the site says so" is a claim about whatever server answered you.

curl -s https://snoozebear.xyz/ca.html | sha256sum

Three hops, and none of them asks you to trust the previous one. That is the whole of it — there is no fourth hop where you have to believe us.

Two things about this address that will look wrong

1

It probably does not end in pump.

Almost every pump.fun token you have seen has a mint address ending in pump, because pump.fun's own frontend grinds for that suffix. Ours may not. The suffix proves nothing either way — it is four characters anybody can grind for a few seconds of CPU, and scammers grind it precisely because people read it as a credential. Read the whole address, or read this page. Do not read the last four characters.

2

A Solana address has no checksum.

An Ethereum address carries EIP-55 capitalisation, so a single mistyped character is detectable by the wallet before you send. Base58 carries nothing. A typo that lands on a real account is indistinguishable from the address you meant. Copy it; never retype it, and never read it off a screenshot.

What this page does not do

It does not read the chain. It publishes a constant and tells you how to check it, because a page that fetched a price could be showing you a price from anywhere, and the one thing worth being certain about here is the address. It connects to no wallet, has no buy button, and takes no fee.

It also cannot tell you the token is worth anything, that the launch went well, or that anybody else is buying. Those are not facts this page has.
