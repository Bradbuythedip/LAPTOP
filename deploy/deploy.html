A local page. It builds the transactions and reads the answers back; your wallet signs. Nothing here holds a key, and nothing here talks to any server — every read goes through your wallet's own provider.

This file must never be moved into web/. Every page on the site is checked to contain no signing or sending method, and that check is the site's whole clone defence — “if a page like this asks you to sign, it is not ours”. This page sends eth_sendTransaction, so putting it there would delete that property for all nine pages at once. test/run.mjs fails the build if it appears under web/.
